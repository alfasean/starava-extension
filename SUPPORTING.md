# Supporting Strava Run Analyzer

This project is and will stay **100% free**: no backend, no accounts, no
upsells, no feature behind a paywall. Funding is entirely optional and never
expected.

If the extension helped you understand your training a bit better and you
want to say thanks, the nicest way is a one-time tip through
**[GitHub Sponsors](https://github.com/sponsors/alfasean)**.

Where it goes:

- API credits used to test the extension against the supported providers
- coffee that keeps the maintenance going 🏃

What it does **not** buy:

- priority features, paid support tiers or influence on the roadmap. Issues
  and pull requests are treated the same for everyone, sponsors or not.

No obligation to do anything: starring the repo, sharing it with a running
club, or filing a good bug report are all worth just as much.
